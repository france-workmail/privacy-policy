# Privacy policies

Privacy policies for my apps. Every page is published with GitHub Pages at **https://france-workmail.github.io/privacy-policy/**.

| App | Folder | Privacy policy URL (use in Play Console) | Data deletion URL |
|---|---|---|---|
| Tongits Battle | `tongits-battle/` | https://france-workmail.github.io/privacy-policy/tongits-battle/ | https://france-workmail.github.io/privacy-policy/tongits-battle/delete-account.html |
| Audify | `audify/` | https://france-workmail.github.io/privacy-policy/audify/ | none (the app stores no personal data) |

## How a file maps to a URL
`<folder>/index.html` is served at `https://france-workmail.github.io/privacy-policy/<folder>/`, and any other file at `https://france-workmail.github.io/privacy-policy/<folder>/<file>`.

## Adding an app
1. Create a folder, for example `myapp/`, and add an `index.html` with that app's policy.
2. Add a link to it in the root `index.html` and a row to this table.
3. Commit to `main`. Pages redeploys in about a minute, and the policy is then at `https://france-workmail.github.io/privacy-policy/myapp/`.
